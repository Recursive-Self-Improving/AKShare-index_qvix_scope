# Repository guidance

## Lessons

- Use `uv sync --frozen` with Python 3.14 and this lock. AKShare 1.20.53 is the last approved version with `index_news_sentiment_scope`; 1.20.54 removed it. The installed JavaScript decoder imports `py_mini_racer`, but its distribution metadata name is `mini-racer` (not `py-mini-racer`).
- Capture `requests` response-hook `.content` before application decoding, including redirect responses; these are HTTP-decompressed bytes, not wire bytes. Request read/connect timeouts alone are not wall-clock bounds: acquisition uses one 45-second subprocess per source.
- Historical AKShare documentation puts the sentiment anchor immediately before its own `###` title. Splitting at the first heading yields an empty excerpt; bound the exact example using its explicit final dataframe row-count/fence, then transcribe only printed dated rows.
- Sina first observation is not official index inception. Store authoritative base/release dates and per-row pre-release/pre-base flags. In particular, vendor 沪深300 history starts before both official base and release; its reconstruction method remains unknown. 科创综指 includes dividends and is not the 科创50 price index.
- Keep provider failures nonzero and documentation examples separate. A successful offline report/hash check cannot establish genuine sentiment availability or browser interaction correctness. Never edit the orchestrator's goal ledger from an implementation slice.
- AKShare 1.20.53's sentiment wrapper raises a pandas column-projection KeyError for a valid HTTP200 `[]`. Keep the actual invocation/capture; recognize only that empty projection and strictly decode the captured body before treating it as observed empty success. Coverage of merged sentiment must be derived from all successful revisions, separately from the latest response; never rewrite an immutable acquisition manifest to migrate derived accounting.
- RQData documents `rqdatac.news.get_stock_news` with per-article and per-company sentiment from 2017; this is a separately entitled alternative, not proof of the same ChinaScope market index. CnOpenData/通联 documents company-level daily news sentiment indices, not the original market series. Vendor history and redistribution remain subject to actual access and license.
- Root `ruff check .` includes archived `.py` evidence scripts; run final union lint after reviewers add scripts.
- AKShare 1.20.53 `index_option_50etf_qvix` reads the first five columns of a GBK CSV via `http.get_buffer`; its 2026-11-15 response contained unordered dates and two conflicting 2026-11-02 values. Successful wrapper execution is not validated history; never silently deduplicate or infer dates.
- The provider's HTTPS `k.csv` matched the 2026-11-15 pinned-wrapper HTTP body byte-for-byte, and its historical chart script uses the same file. This does not authenticate the earlier HTTP transfer or independently resolve source conflicts; TLS, source quality, and redistribution permission are separate questions.
- QVIX quality normalization compares complete decoded OHLC tuples, not close alone: equal-close/different-open candidates still conflict and all four selected fields must be null. Keep source-order wrapper output and every one-based raw ordinal separately from sorted unique-date observations; normalization notices must not conceal quality defects outside the selected window.
- Bind a common comparison trace to its snapshot's verified comparator identity/hash, including original comparator staleness. A later index refresh must not silently change the calendar of a stale QVIX snapshot.
- QVIX full-calendar accounting must replay the comparator's full retained Sina raw history, not its request-filtered CSV. Selected holes are the full in-observed-bounds hole set filtered to the request, even when no source row survives. Keep immutable acquisition references/times mandatory; a derived format migration is not a fetch.
- `report.html` visible wording is a verified contract: `app/verify.py` (`visible_index`/`visible_qvix`) independently rebuilds the exact per-panel disclosure text, and `test_visible_disclosure_removal_and_contradiction` tampers with specific substrings. Any wording change in `app/chart.py` must update both.
