## Sentiment: actual invocation and limits

`akshare==1.20.65` accessing `ak.index_news_sentiment_scope` raised `AttributeError: index_news_sentiment_scope 已在 1.20.54 移除，原因与替代接口见更新日志 https://akshare.akfamily.xyz/changelog.html#v1-20-54`. That [changelog](https://akshare.akfamily.xyz/changelog.html#v1-20-54) attributes removal to the provider's failed certificate and timeouts, not an equivalent replacement.

Actually invoked `akshare==1.20.53` `ak.index_news_sentiment_scope()` with `akshare.utils.http.get` wrapped to inject timeout `(5,12)`: `SSLError: HTTPSConnectionPool(host='www.chinascope.com.cn', port=443): Max retries exceeded with url: / (Caused by SSLError(SSLCertVerificationError(1, '[SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed: unable to get local issuer certificate (_ssl.c:1081)')))`. No sentiment response/data was retrieved; its actual available range and count are **unknown**, not zero historical existence. Do not invent a response or treat HTTP failure as an empty dataset.

Installed 1.20.53 `akshare/index/index_zh_a_scope.py` defines a **zero-argument** function: GET `https://www.chinascope.com/inews/senti/index` with only `period=YEAR`, then parses JSON array fields `tradeDate`, `maIndex1`, `marketClose` as 日期, 市场情绪指数, 沪深300指数. It exposes no start/end date or pagination. This proves the wrapper does not offer backfill parameters; `YEAR` suggests a rolling year but neither its duration nor server-side history limits can be measured now. See the [independent wrapper source](https://docs.rs/akshare/latest/src/akshare/index/scope.rs.html), which also requests YEAR; it is not evidence of successfully retrieving data. Its substitution of missing sentiment with zero must not be copied.

Direct probes of the same genuine source, not a substitute sentiment series:

- Original HTTPS endpoint with `period=YEAR`, `ALL`, `MAX`, `MONTH` and normal certificate validation all hit the same certificate error after redirect.
- Diagnostic only, `verify=False`: both YEAR and ALL returned `301 Location: https://www.chinascope.com.cn`, discarding path and query, then status 200 **text/html homepage**, not sentiment JSON. Original HTTP redirected to `https://dnspod.qcloud.com/static/webblock.html?d=www.chinascope.com`, also HTML. The former research page `https://www.chinascope.com/reasearch.html` likewise redirected to homepage.
- Preserving the old path manually on the new host, `https://www.chinascope.com.cn/inews/senti/index?period={YEAR,ALL,MAX,MONTH}`, failed certificate verification; with verification disabled for diagnosis only, each timed out at 10 seconds. None establishes a supported parameter or historic range. Never disable verification as a production workaround.
- Wayback CDX request `https://web.archive.org/cdx/search/cdx?url=www.chinascope.com/inews/senti/index*&output=json&filter=statuscode:200&collapse=urlkey&limit=10` timed out after 10 seconds. No same-source archive or successful provider alternate was found in this bounded probe; this is not proof none exists. Provider access, a valid archived response, or restoration of its API is an external blocker to genuine sentiment data and the requested real dual-series overlays. A different sentiment measure is not equivalent without a decision.

## Seven daily index histories

Actual calls used AKShare 1.20.53 `ak.index_zh_daily_sina(symbol=...)`, with `akshare.utils.http.get` wrapped for `(5,12)` timeout. The wrapper GETs `https://finance.sina.com.cn/realstock/company/{symbol}/hisdata/klc_kl.js?d=2020_2_4` and decodes the compressed upstream response using AKShare's JavaScript decoder. It accepts symbol only, not dates; filter decoded records locally, without interpolation. Returned columns: `date, open, high, low, close, volume`. AKShare 1.20.65 exposes the same named interface; production must pin and check its actual behavior rather than assume future compatibility. Source warns that bulk requests can cause IP blocking; seven sequential requests, finite timeouts, no aggressive retry.

As a **relative** gap check, compare each returned date set to the observed 上证指数 dates within that series' first–last range: all six had 0 missing and 0 extra. This is not an independent official trading calendar and cannot prove no common omissions; persist the actual missing-date list and calendar source in production. Earlier dates are not automatically pre-inception: source-unavailable, before base date, and before public release need distinction. In particular, [SSE's official 2025-01-08 announcement](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20250108_10767835.shtml) states 科创综指 would formally launch 2025-01-20, yet Sina returns 2020 onward: pre-launch records are retrospective/back-calculated, not historical real-time investable observations. Likewise 沪深300 begins with OHLC all 1316.455 and zero volume in 2002; verify official release and characterize pre-publication rows before backtesting. Other series may also have retrospective history. `000680` and `000688` are distinct indices, not ETFs; [SSE announcement and linked notice](https://www.sse.com.cn/market/sseindex/diclosure/c/c_20250108_10767836.shtml) establish their distinct names. 创业板50 is `sz399673`, not 创业板指 `sz399006`.

## Bounded implementation plan for review

1. Pin dependencies and versions; run a sequential, timeout-enforced acquisition command such as `python -m app.fetch --start 2000-01-01 --end YYYY-MM-DD --output data`. These commands are proposed interfaces, **not yet runnable**. Fetch seven Sina responses and retain original compressed HTTP bytes plus request URL/parameters, timestamp UTC, HTTP status/content type, SHA-256 and decoder/version; retain normalized CSV (`date,close` and optionally original OHLCV) per symbol. Capture error metadata on failures; do not overwrite a prior good snapshot. Decode exactly the obtained bytes, not a second unrecorded fetch; verify source name/code mapping independently and validate dates, unique keys, numeric closes, and date order before atomic promotion. Respect endpoint throttling; no fabricated values. Record provenance, observed ranges/counts, duplicate/gap checks, calendar comparison limits, and pre-release back-calculation separately from truly pre-inception or source-unavailable intervals.
2. Try the historical AKShare 1.20.53 zero-argument sentiment call once under timeout with normal certificate validation, recording the failure; alternatively a separate pinned environment/subprocess avoids conflicting AKShare versions. On a genuine successful response, retain raw JSON bytes and headers/hash, normalized `date,sentiment,market_close`, per-row missing values, UTC retrieval, query, source/version and range. A direct request reproducing that exact endpoint can save wire bytes but does not replace the required actual AKShare invocation. Merge actual same-source historical snapshots only by date with explicit conflict/version handling; never forward-fill, interpolate, or silently swap metrics. Failure is a visible blocker; leave sentiment absent and report error, not a fake CSV. Re-examine provider access/archive only when a real route is available; undocumented `ALL`/`MAX` are not established.
3. Proposed chart command `python -m app.chart --input data --output report.html`: one static self-contained HTML containing seven labeled Plotly subplots, each index close on left y-axis and same real sentiment on right y-axis, real dates, null breaks, no forward-fill; explicit drag zoom, range navigation and reset/autoscale. With sentiment absent show a prominent missing-data warning and no fabricated trace; this is only a partial artifact, not completion of dual-overlay AC. Embed Plotly JS once and embed chart data: Plotly Python `plotly.offline.get_plotlyjs()` plus one HTML document is straightforward and works from `file://` without CDN; verify version/license and actual offline behavior. Seven separate `to_html(include_plotlyjs=True)` fragments unnecessarily duplicate JS; `include_plotlyjs='cdn'` is not offline; separate vendored JS is smaller for repeated reports but violates single-file portability unless inlined at build. Plotly drag zoom supports date axes; verify in a gated browser, including reset and no external requests, before claiming chart behavior.
4. Metadata and README should document exact runnable commands after implementation, source publication/revision unknowns, timezone and retrieval times; observed date is not evidence of same-day availability. No same-day backtest or causal claim without separately established publication timestamps, lag assumptions, and retrospective-index flags. Offline check should compare embedded traces with CSV, test gaps, and show seven axes/labels; a visual browser test must follow the project heavy-gate policy. No scheduler.

Alternatives: Eastmoney `index_zh_hist_em(symbol, period, start_date, end_date)` internally looks up code/market and requests `https://push2his.eastmoney.com/api/qt/stock/kline/get` then filters locally; market-code mapping can be ambiguous and its live behavior was not probed here. CSI `index_hist_csindex` has explicit dates and is useful for cross-checking its covered indices, but its coverage and live behavior were not tested. Neither is a substitute for ChinaScope sentiment. Sina history depth is observed rather than a guarantee of full historical availability or future service.
